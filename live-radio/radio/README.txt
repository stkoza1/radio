اللاسلكي المباشر + جدول مهام اليوم
===================================
تشغيل على جهازك للتجربة:
  node server.js   ثم افتح http://localhost:3000
  (المايكروفون في المتصفح يشتغل على localhost أو على رابط https فقط)

نشره على الإنترنت (مجاني تقريباً) عبر Render.com:
  1) ارفع المجلد كله إلى مستودع GitHub جديد.
  2) في Render: New + ثم Web Service ثم اختر المستودع.
  3) Runtime: Node  |  Build Command: فاضي أو  npm install  |  Start Command: node server.js
  4) بعد النشر تحصل على رابط https يفتحه أي شخص من آيفون أو كروم.

ملاحظة: الخطة المجانية تنام بعد فترة خمول وأول فتح يتأخر شوي.
المنطقة الزمنية للجدول: Asia/Riyadh (تغييرها بمتغير TZ_NAME).
